# 🐍 For e Estruturas de Decisão em Python

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python\&logoColor=white)

📚 Projeto desenvolvido para praticar **laços de repetição** e **estruturas de decisão** em Python.

## 🎯 Objetivo

Aprender a utilizar:

* 🔄 `for` — repetição
* 🤔 `if` — condição
* 🔀 `elif` — outra condição
* ❌ `else` — caso contrário

## 💻 Exemplo

```python
for numero in range(1, 6):
    if numero % 2 == 0:
        print(numero, "é par")
    else:
        print(numero, "é ímpar")
```

## 🚀 Resultado

```text
1 é ímpar
2 é par
3 é ímpar
4 é par
5 é ímpar
```

## 🔄 Estrutura `for`

O `for` permite **repetir um bloco de código**.

```python
for numero in range(1, 6):
    print(numero)
```

## 🤔 Estrutura de decisão

O `if`, `elif` e `else` permitem que o programa **tome decisões**.

```python
idade = 20

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
```
